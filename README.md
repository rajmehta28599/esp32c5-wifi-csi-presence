# esp32c5-wifi-csi-presence
 ESP32-C5 Wi-Fi CSI human-presence detector, taught as 10 standalone ESP-IDF projects. Step 08: self-calibrating presence detector. Step 10: experimental 0/1/2+ counting, breathing and heart rate. Host-tested; not yet validated on hardware. Includes a sourced comparison of presence, people-counting and vital-sign sensors
